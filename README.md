Bounty page: https://make.fun/bounty/ai-excited-01

## Run

```sh
node main.ts
```

`main.ts` is the entrypoint and copies `entry.png` into the output directory (defaults to `output/`; override with `MAKEFUN_OUTPUT_DIR`).
